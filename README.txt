Random Quote Generator — это графическое приложение на Python, которое генерирует случайные научные цитаты из предопределённого списка. Программа обладает следующими функциями:

Генерация случайных цитат — при нажатии кнопки «Сгенерировать цитату» выбирается случайная цитата из списка научных высказываний.

Отображение текущей цитаты — выбранная цитата отображается в текстовом поле с указанием автора и темы.

История цитат — все сгенерированные цитаты сохраняются и отображаются в виде списка.

Фильтрация истории — возможность фильтровать историю по автору и по теме цитаты.

Сохранение истории — история генерируемых цитат автоматически сохраняется в JSON‑файл и загружается при следующем запуске программы.

Проверка корректности данных — программа проверяет корректность внутренних данных (предопределённый список цитат не должен содержать пустых полей).

Целевая аудитория: студенты, преподаватели, любители науки и философии, все, кто ищет вдохновение в мудрых высказываниях.

Используемые технологии:

Python 3;

библиотека tkinter для создания графического интерфейса;

библиотека json для сохранения и загрузки истории;

стандартная библиотека random для случайного выбора цитаты.

Инструкция по запуску
Требования:

Установленный Python 3.6 или выше.

Шаги по запуску:

Сохраните полный код программы в файл с именем quote_generator.py.

Убедитесь, что у вас есть права на запись в директорию, где будет запускаться скрипт (для создания файла quote_history.json).

Откройте терминал (командную строку) и перейдите в директорию с файлом quote_generator.py.
 
Запустите программу командой: python quote_generator.py
После запуска откроется окно приложения.

Примеры использования
Пример 1. Генерация случайной цитаты

Запустите приложение.

Нажмите кнопку «Сгенерировать цитату».

В текстовом поле появится случайная цитата, например:

«Математика — это язык, на котором написана книга природы.»
— Галилео Галилей (математика)

Эта цитата добавится в историю, которая отобразится в списке ниже.

Пример 2. Просмотр истории цитат

Сгенерируйте несколько цитат подряд (нажмите кнопку «Сгенерировать цитату» 3–5 раз).

Прокрутите список истории (при необходимости используйте полосу прокрутки), чтобы увидеть все ранее сгенерированные цитаты. Каждая запись в списке имеет номер и краткое содержание (первые 50 символов текста).

Пример 3. Фильтрация по автору

В выпадающем списке «Автор» выберите, например, «Альберт Эйнштейн».

Список истории автоматически обновится и покажет только цитаты этого автора (например, «Воображение важнее знания.» и «Все должно быть изложено так просто, как только возможно, но не проще.»).

Чтобы сбросить фильтр, нажмите кнопку «Сбросить фильтры».

Пример 4. Фильтрация по теме

В выпадающем списке «Тема» выберите, например, «физика».

В истории останутся только цитаты на тему физики (например, высказывания Ричарда Фейнмана, Нильса Бора и Альберта Эйнштейна).

Для сброса фильтра используйте кнопку «Сбросить фильтры».

Пример 5. Работа после перезапуска

Сгенерируйте и сохраните несколько цитат.

Закройте приложение (крестик в углу окна).

Снова запустите программу командой python quote_generator.py.

Вы увидите, что история цитат загрузилась из файла quote_history.json и отображается в списке. Фильтры также будут обновлены на основе сохранённых данных.

Примечания
Файл quote_history.json создаётся автоматически в той же директории, что и скрипт. Он содержит массив объектов JSON с полями text, author, topic.

Если файл quote_history.json отсутствует, программа создаст новую пустую историю.

Предопределённый список цитат встроен в код и содержит 10 высказываний на научные темы.

Программа не позволяет добавлять новые цитаты через интерфейс — список фиксирован.

При пустом списке предопределённых цитат (ошибка в коде) программа выдаст предупреждение.
